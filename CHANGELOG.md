# Changelog

## v2.0.0 — first open-source release

- The bot now runs entirely on your phone. No account, sign-in, subscription, or server needed.
- Telegram alerts are optional and use your own bot. Create one with @BotFather, paste its token in
  Settings → Alerts, message the bot once, then tap **Detect** to fill in your chat ID.
- Recent Claims history is now stored on the phone (last 100 claims).
- Setup wizard trimmed to: Accessibility → Overlay → Notifications → Telegram (optional) → Filters.
